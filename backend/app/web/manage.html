Library services

Automatic matching stays conservative. Ambiguous titles appear in Artwork review for your approval.

Movies and shows, grouped as they appear on your TV.

Choose the correct match for titles that need a second look.

Local tracks, embedded captions, and OpenSubtitles downloads.

Downloads use your configured API key and daily budget. Some files have no matching text subtitles. Embedded DVD subtitles are converted automatically to text captions in the background.

Review detected intros or correct an episode’s timing.

Automatic detection needs matching openings across episodes. Manual times are seconds from the start and apply only to the selected file.

Show Up next as a movie’s credits begin, rather than at the end of the file.

Gravyflix automatically reads credit chapters and analyzes ending frames locally. Confident matches are saved; unclear endings keep the final 30-second fallback. The initial library pass takes time. You can review or correct a detected start below as HH:MM:SS. Episodes keep their existing timing.

Settings are saved to this installation’s .env file. Restart the server to apply changes.

Apply saved settings

Restart the server when nobody is watching. For a foreground server, use Ctrl-C and run ./scripts/start.sh again.

            02
            
Connect a Roku

            

              Open this dashboard using the server’s LAN address, rather than
              localhost. The downloaded app will use that same address.
            

            

            
            

              Enable developer mode: Home ×3, Up ×2, Right, Left, Right, Left,
              Right. Follow the prompts and set a developer password.
            

            

              Visit http://YOUR_ROKU_IP in a browser. Sign in as
              rokudev with that password. Upload the ZIP
              through the Development Application Installer.
            

            

              Reinstall after Roku app changes. Backend changes do not require
              reinstalling the app.
            

          

          

            03
            
Connect a Vizio / Cast TV

            

              Enter the TV’s LAN address and a friendly name in Server settings.
              Save and restart the server.
            

            

              On Android, open Gravyflix in Chrome. On iPhone or iPad, use
              Safari or Chrome. Connect to the same home Wi-Fi, choose a title
              and press Play on TV. Your phone or tablet remains the remote;
              no mobile app is required.
